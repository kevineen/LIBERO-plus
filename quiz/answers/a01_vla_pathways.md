# a01 — 解答（VLA 経路）

## 選択

| 問 | 正答 | 解説 |
|----|------|------|
| Q1 | **B** | TurboVLA は V+L→A（LLM 非中心の直接融合）を主張する |
| Q2 | **B** | chunk = 複数ステップ分のアクション列 |
| Q3 | **C** | 学習・評価のホライズン契約を一致させる |
| Q4 | **B** | 依存分離・ホスト役割分担が主目的（成功率保証ではない） |
| Q5 | **B** | 公式は server ↔ client 分離 |

## 短答（模範）

**S1.** 毎ステップ（または頻繁に）巨大 LM を通すため、計算・メモリが重くなりやすい。

**S2.** 政策が出した 8 ステップを超えて 16 ステップ実行すると、未予測区間を open-loop で進めることになり、評価プロトコルが論文・学習時と一致しない。

**S3.** 重い推論とシミュレーション／実機 I/O を分け、環境依存を隔離できる点が共通。
