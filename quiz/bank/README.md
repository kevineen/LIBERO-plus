# 問題バンク（gate 以外）

gate（必須）は親ディレクトリの `q01`〜`q05`。  
ここは **復習（easy）と発展（hard）** のストックです。誤答タグごとに足していきます。

## 追加ルール

1. 誤答が集中した **タグを1つ**決める
2. 必要なら先に [`study/remediation/`](../study/remediation/) に易しい補足を書く
3. 該当 `0X/` に **選択2 + 短答1**（easy）を追加
4. 再テストはその追加分だけでよい（gate 全問やり直しは任意）
5. 各問の先頭に HTML コメントでメタを付ける:

```markdown

```
