# 補足教材（Remediation）

本線の章でつまずいたときの **易しい説明** を置く場所です。本線 Markdown は長くしません。

## 使い方

1. gate クイズ（`quiz/qXX_*.md`）を解く
2. [`quiz/rubric.md`](../quiz/rubric.md) で判定する
3. 誤答タグに対応する `0X/` 配下を読む
4. [`quiz/bank/0X/`](../quiz/bank/) の easy で再確認する

## 追加ルール（1トピック = 1ファイル）

新しい補足を足すとき:

1. ファイル名は短く具体的に（例: `easier_chunk_vs_openloop.md`）
2. 中身は **比喩 + 要点3つ以内 + 反例1つ** まで
3. 先頭に `tags:` を書く（クイズ bank と同じタグ）
4. そのフォルダの `README.md` の表に1行追加する
